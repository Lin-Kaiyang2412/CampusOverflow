## 2. 为什么当初会这样（历史说明）

`docs/学生任务清单.md` 写得很清楚：共 **107 个待实现方法，分布在 32 个文件**，每个都带 `TODO(Sx)` 标记。
基线只提供骨架 + 测试，实现要学生填。所以：

- **测试是真的需求说明书。** 先读测试，再写实现，让它变绿。
- **在 S2/S3 的方法填完之前，后端测试不可能全绿。** 这是课程设计，不是团队失误。

（这一节描述的是 10-22 时的状态，现已不适用——见 §0。）
